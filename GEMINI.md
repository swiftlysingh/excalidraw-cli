# excalidraw-cli

This Gemini CLI extension ships the `excalidraw-cli` skill for creating editable Excalidraw diagrams from DSL, JSON, or Graphviz DOT, then exporting PNG or SVG without a browser.

When the user wants a flowchart, architecture diagram, decision tree, `.excalidraw` file, or an image export of one, use the `excalidraw-cli` skill.

Run the CLI with `npx --yes @swiftlysingh/excalidraw-cli` unless `excalidraw-cli` is already on PATH or this repo has been built (`node dist/cli.js`).
